# QIS 서버 — 사내 품질정보시스템

개인 PC에서 쓰던 QIS(HTML) 화면을 그대로 쓰면서, 데이터를 **사내 서버 한 곳**에 두고 품질팀이 함께 쓰는 버전입니다.

> 📘 **[설치 가이드](docs/설치_가이드.md)** — 서버 PC 설치 · 기존 데이터 가져오기 · 계정 · 방화벽 · HTTPS · 백업 · 복원 · 문제 해결 (관리자용)
> 📗 **[사용 가이드](docs/사용_가이드.md)** — 접속 · 로그인 · 권한 · 동시 작업 · 연결 끊김 · 첨부 · 출력 (팀원용)

- **사내망 전용**: 데이터는 서버 PC의 DB 파일 하나(`data/qis.db`)와 첨부 폴더에만 있고, 외부 인터넷 서비스와 연결하지 않습니다.
- **로그인 · 권한**: 사용자마다 계정이 있고 역할은 세 가지입니다.

  | 역할 | 할 수 있는 일 |
  |---|---|
  | 조회 | 보기 · 검색 · 출력 |
  | 작성 | 불량 · NCR · 귀책 · RCA · 입고 등록 · 수정, 협력사 · 부품 추가 · 수정 |
  | 관리자 | 작성 + 기준정보 삭제, BOM 교체, 설정, 사용자 · 변경 이력 · 백업 관리 |

- **변경 이력(감사 추적)**: 모든 등록 · 수정 · 삭제 · 첨부 · 로그인을 "누가 · 언제 · 무엇을 · 이전 값 → 새 값"으로 남깁니다.
  - 이력은 DB에서도 고치거나 지울 수 없습니다(트리거로 차단).
  - 기록을 고치면 바로 앞 내용이 이전 버전으로 보관됩니다.
- **동시 작업**: 같은 기록을 두 사람이 고치면 서버가 항목별로 합칩니다.
  - 서로 다른 항목을 고쳤으면 둘 다 남습니다.
  - 같은 항목을 고쳤으면 나중에 저장한 값이 남고, 화면 안내와 함께 이력에 '동시 수정'으로 기록됩니다.
  - 다른 사람의 변경은 15초 안에 화면에 반영됩니다.
- **자동 백업**: 매일 새벽 DB 사본 · 기록 JSON · 첨부 사본을 백업 폴더에 저장합니다. 백업 폴더는 네트워크 드라이브를 권장합니다.
- **데이터 유실 방지**
  - 서버 연결이 끊기거나 로그인이 만료돼도, 고친 내용은 창에 남아 있다가 다시 연결되면 저장됩니다.
  - 지운 첨부는 휴지통 폴더로 옮겨집니다.

## 가장 쉬운 시작 (더블클릭 한 번)

Python 3.11 이상만 설치돼 있으면, 폴더 맨 위의 파일 하나로 설치부터 실행까지 됩니다.

| PC | 실행할 파일 |
|---|---|
| Windows | `start-windows.bat` |
| Mac | `start-mac.command` |

- **처음 실행할 때**
  - 필요한 프로그램을 설치하고 관리자 계정(아이디·이름·비밀번호)을 묻습니다.
  - 서버를 켜고 브라우저를 엽니다.
- **다음부터:** 바로 서버가 켜지고 브라우저가 열립니다. 이미 켜져 있으면 브라우저만 엽니다.
- **접속 주소:** 창에 핸드폰·다른 PC용 주소가 표시됩니다. 창을 닫거나 `Ctrl+C`를 누르면 서버가 멈춥니다.
- **Mac에서 처음 열 때:** "확인되지 않은 개발자" 경고가 나오면 파일을 **오른쪽 클릭 → 열기**를 누릅니다. 그래도 안 되면 터미널에서 `bash start-mac.command`로 실행합니다.

아래의 `scripts/windows/` 방법도 그대로 쓸 수 있습니다. 자동 시작 등록(`register_startup.bat`)은 그쪽 파일을 씁니다.

## 설치 (Windows 서버 PC)

1. **Python 3.11 이상**을 설치합니다([python.org](https://www.python.org)). 설치할 때 *Add python.exe to PATH*를 체크하세요.
2. 이 폴더(`qis-server`)를 서버 PC에 복사합니다. 예: `D:\QIS\qis-server`
3. `scripts\windows\install.bat`을 실행합니다. 프로그램을 설치하고 첫 관리자 계정을 만듭니다.
   - 서버 PC에서 인터넷이 안 되면, 인터넷 되는 PC에서 다음 명령으로 받은 `wheels` 폴더를 함께 복사합니다.
     ```
     pip download -r requirements.txt -d wheels
     ```
4. `scripts\windows\run.bat`으로 실행한 뒤, 브라우저에서 `http://서버PC이름:8080` 으로 접속합니다.
5. 다른 PC에서 접속하려면 서버 PC 방화벽을 엽니다. 관리자 권한 명령 창에서 실행합니다.
   ```
   netsh advfirewall firewall add rule name="QIS" dir=in action=allow protocol=TCP localport=8080
   ```
6. PC가 켜질 때 자동으로 실행하려면 `scripts\windows\register_startup.bat`을 관리자 권한으로 실행합니다.

## 처음 설정

| 할 일 | 방법 |
|---|---|
| 기존 QIS 데이터 가져오기 | 개인 QIS에서 **설정 › 데이터 · 백업 › 지금 백업**으로 받은 JSON(사진 포함)을 준비합니다. 관리 화면 › 백업 · 데이터 › **기존 QIS 데이터 가져오기**에서 선택하거나, 명령 `python -m qis import 백업파일.json`을 씁니다. **빈 서버에 한 번만** 가져올 수 있습니다. |
| 사용자 추가 | QIS 상단 **관리** › 사용자에서 아이디 · 이름 · 역할 · 임시 비밀번호를 넣습니다. 처음 로그인하면 본인 비밀번호로 바꾸게 됩니다. |
| 회사 정보 · 기준값 | 관리자가 QIS **설정**에서 바꿉니다 (작성 권한은 설정 탭이 보이지 않음). |

## 설정 파일 (`data/qis.json`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `port` | 8080 | 접속 포트 |
| `ssl_certfile` · `ssl_keyfile` | (비움) | 사내 인증서 파일 경로. 둘 다 넣으면 HTTPS로 실행됩니다 |
| `backup_dir` | `data/backup` | 백업 폴더. 다른 PC · 네트워크 드라이브 권장 (예: `\\\\fileserver\\QIS백업`) |
| `backup_keep` | 30 | 날짜별 DB 사본 보관 개수 |
| `backup_hour` | 2 | 매일 이 시각 이후 첫 확인 때 백업 |
| `session_hours` | 12 | 마지막 사용 후 로그인 유지 시간 |
| `login_max_fail` · `login_lock_minutes` | 5 · 10 | 연속 실패 시 잠금 |
| `max_file_mb` | 30 | 첨부 1개 최대 크기 |

설정을 바꾼 뒤에는 서버를 다시 시작합니다.

## 백업 · 복원

백업 폴더에는 세 가지가 쌓입니다.

| 폴더 | 내용 | 쓰임 |
|---|---|---|
| `db/qis_YYYYMMDD_HHMM.sqlite` | DB 전체 사본 | 복원용 |
| `json/QIS_서버백업_YYYYMMDD.json` | 기록 전체 | 서버를 쓸 수 없을 때 개인 QIS 화면에서 *백업으로 교체*로 열어 조회 |
| `files/` | 첨부 사본 | 새 파일만 복사하고, 지우지 않음 |

**복원 순서**

1. 서버를 멈춥니다.
2. `data/qis.db`를 다른 이름으로 옮겨 둡니다.
3. 원하는 날짜의 `qis_….sqlite`를 `data/qis.db`로 복사합니다.
4. 백업의 `files/` 내용을 `data/files/`에 덮어씁니다.
5. 서버를 다시 시작합니다.

관리 화면 › 백업 · 데이터에서 **지금 백업**, **내보내기(JSON)**를 할 수 있습니다.

## 명령

```
python -m qis init                      처음 설치 (설정 파일 · 첫 관리자)
python -m qis serve                     서버 실행
python -m qis import 백업.json           기존 QIS 백업 가져오기 (빈 서버)
python -m qis backup                    지금 백업
python -m qis adduser 아이디 --name 이름 --role editor|viewer|admin
python -m qis resetpw 아이디             비밀번호 초기화 (관리자 비밀번호 분실 시)
```

## 보안 요약

- **비밀번호**
  - scrypt 해시로만 저장합니다.
  - 8자 이상 · 영문+숫자여야 하고, 아이디를 포함할 수 없습니다.
  - 5회 실패하면 10분 동안 잠깁니다.
- **세션**
  - 쿠키는 HttpOnly · SameSite=Strict입니다.
  - DB에는 토큰 해시만 저장합니다.
  - 권한이 바뀌거나 사용이 중지되면 즉시 로그아웃됩니다.
- **위조 요청 차단**: 변경 요청은 전용 헤더가 있어야 처리합니다.
- **화면 보안 정책(CSP)**
  - 외부 사이트로 데이터를 보내거나 외부 스크립트를 불러올 수 없습니다.
  - 화면은 문자열 코드 실행(eval)을 쓰지 않습니다.
- **권한은 서버에서 검사**: 화면을 조작해도 권한 밖의 저장은 거부됩니다.
- **이력**: 변경 이력은 추가만 가능합니다(수정 · 삭제 불가). 내보내기 · 백업도 기록됩니다.

## 개발 · 시험

```
pip install -r requirements.txt pytest httpx playwright
python -m pytest -q                         # API 시험
python tests/e2e_browser.py tests/sample_backup.json       # 화면 시험 (두 사람 동시 작업 · 권한 · 끊김 · 만료 · 관리 화면)
```

화면(`qis/web/index.html`)은 QIS 단일 파일과 같은 소스입니다. 서버에서 열리면 서버 모드로 동작합니다.
