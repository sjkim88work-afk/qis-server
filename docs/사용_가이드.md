# QIS 사용 가이드 (품질팀 · 관련 부서)

QIS는 사내 서버에 있는 품질정보시스템입니다. 프로그램 설치 없이 **브라우저(Edge · Chrome)로 접속**해서 씁니다.

## 1. 접속 · 로그인

1. 브라우저 주소창에 관리자에게 받은 주소를 입력합니다. 예: `http://qis-server:8080`
   - 자주 쓰면 즐겨찾기에 추가하세요.
2. 아이디와 임시 비밀번호로 로그인합니다.
3. **처음 로그인**하면 비밀번호 변경 화면이 나옵니다. 본인만 아는 새 비밀번호로 바꿔야 QIS를 쓸 수 있습니다.
   - 8자 이상이어야 합니다.
   - 영문과 숫자를 모두 넣어야 합니다.
   - 아이디는 넣을 수 없습니다.

**알아 둘 점**
- 비밀번호를 5번 틀리면 10분 동안 잠깁니다.
- 비밀번호를 잊었으면 관리자에게 초기화를 요청하세요.
- 12시간 동안 쓰지 않으면 자동으로 로그아웃됩니다.

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 왼쪽 | 회사명 · **서버 저장 시각** (마지막으로 서버에 저장된 시각) |
| 상단 오른쪽 | 👤 이름 · 권한, **비밀번호**(변경), **관리**(관리자만), **로그아웃** |
| 메뉴 | 대시보드 · 이슈 · 불량 관리 · FAR · NCR / 8D · RCA · 협력사 품질 · COPQ · 기준정보 (관리자는 설정 · 백업도 보임) |

화면과 입력 방법은 기존 개인 QIS와 같습니다.

## 3. 권한별로 할 수 있는 일

| 권한 | 할 수 있는 일 | 안 되는 일 |
|---|---|---|
| **조회** | 모든 화면 보기 · 검색 · 출력(통보서 · 8D · 보고서) · 엑셀 내보내기 | 등록 · 수정 · 삭제 · 첨부 |
| **작성** | 불량 등록 · 귀책 조사 · NCR 발행 · 대책서 평가 · 유효성 검증 · RCA · 입고 · 첨부, 협력사 · 부품 추가 · 수정 | 협력사 · 부품 삭제, BOM 교체, 설정 변경 |
| **관리자** | 전부 + 사용자 · 변경 이력 · 백업 관리 | — |

권한 밖의 작업을 하면 "관리자만 할 수 있습니다" 안내가 나오고 저장되지 않습니다. 권한 변경은 관리자에게 요청하세요.

## 4. 저장과 여러 사람이 함께 쓰기

- **저장은 자동입니다.** 저장 버튼을 누르면 바로 서버에 저장되고, 상단에 `서버 저장 HH:MM:SS`가 표시됩니다.
- **다른 사람이 고친 내용**은 15초 안에 내 화면에 반영되고, "○○○의 변경 n건을 받았습니다" 안내가 뜹니다. 작성 창이 열려 있는 동안에는 기다렸다가 창을 닫으면 반영됩니다.
- **같은 기록을 동시에 고친 경우**
  - 서로 다른 항목을 고쳤으면 → 두 사람 내용이 모두 저장됩니다.
  - 같은 항목을 고쳤으면 → 나중에 저장한 값이 남습니다. "다른 사용자가 같은 항목을 먼저 고쳤습니다" 안내가 뜨고, 변경 이력에 '동시 수정'으로 남습니다. 필요하면 상대방과 확인하세요.
- **NCR 번호가 겹치면** "번호 중복" 안내가 뜹니다. 두 사람이 거의 동시에 NCR을 발행한 경우이니 번호를 확인해 고치세요.

## 5. 연결이 끊기거나 로그인이 만료됐을 때

| 화면 안내 | 의미 · 할 일 |
|---|---|
| ⚠ **서버에 연결할 수 없습니다** (빨간 줄) | 네트워크나 서버 문제. 고친 내용은 창에 남아 있고, 연결되면 **자동으로 저장**됩니다. **창을 닫지 마세요.** 계속되면 관리자에게 연락 |
| 🔒 **로그인이 만료되었습니다** | **다시 로그인**을 눌러 새 창에서 로그인한 뒤 그 창을 닫으면, 원래 창의 변경이 자동 저장됩니다 |
| 창을 닫을 때 "저장하지 않은 내용" 경고 | 아직 서버에 보내지 못한 변경이 있음 → **취소**하고 잠시 기다렸다가 닫으세요 |

## 6. 첨부 (사진 · 통보서 · 대책서)

- **불량 사진**: 불량 등록 화면에서 사진을 추가합니다. 자동으로 크기를 줄여 저장합니다.
- **발송한 통보서**: NCR › 발행 정보 › **③ 협력사 통보** 탭의 **+ 발송한 통보서 첨부** (PDF · 메일 · Excel 등)
- **협력사 대책서**: NCR › 대책서 회신 › **+ 대책서 파일 첨부** (PDF · PPT · Excel 등)

**공통**
- 파일당 20MB까지 올릴 수 있고, 끌어다 놓아도 됩니다.
- 첨부는 서버에 저장되어 팀원 누구나 열어 볼 수 있습니다.
- 지운 첨부도 서버 휴지통에 보관되므로, 실수로 지웠으면 관리자에게 요청하세요.

## 7. 출력 · 내보내기

| 하고 싶은 일 | 방법 |
|---|---|
| 부적합 통보서 · 8D 보고서 | NCR 목록의 **발행 정보** → 창 아래 **저장 후 통보서 출력**(조회 권한은 **통보서 출력**), NCR 목록의 **검증** → 창 아래 **8D 출력** → 인쇄 창에서 **PDF로 저장** |
| 목록을 엑셀로 | 각 목록의 **엑셀 내보내기**(.xlsx, 화면 표 그대로) · 모든 표를 한 파일에 담으려면 설정 › 공유 · 내보내기 › **엑셀 통합 파일** |
| 외부(협력사 · 타 부서)에 현황 공유 | 관리자에게 읽기 전용 사본(HTML 파일) 요청. 서버 밖으로 나가는 자료이므로 관리자가 만들어 전달합니다 |

## 7-1. 텔레그램 아침 요약 (관리자)

관리 › **알림 (텔레그램)** 에서 켜면, 매일 정한 시각(기본 08:00)에 서버가 **지연 건 · 오늘 기한 · 이슈 분류 대기**를 텔레그램 그룹으로 한 번 보냅니다. 아무도 접속하지 않아도 보내고, 사용자가 여럿이어도 한 번만 갑니다.

1. 텔레그램에서 **@BotFather** 에게 `/newbot` 을 보내 봇을 만들고 토큰을 받습니다.
2. 받을 그룹에 봇을 초대하고, 그 그룹에 아무 메시지나 한 번 보냅니다.
3. 관리 › 알림에서 토큰을 저장하고 **받을 곳 찾기** → 그룹 선택 → **시험 메시지 보내기** → **자동 전송 켜기**.

- 봇 토큰은 서버 PC의 설정 파일(`data/qis.json`)에만 저장되고, 화면 · 백업 · 변경 이력에는 나오지 않습니다.
- **세부 내용 포함**을 끄면(기본) 번호 · 구분 · 기한만 보냅니다. 조치 제목 · 이슈 제목까지 보내려면 회사 정보 반출 규정을 확인한 뒤 켜세요.
- 회사망에서 텔레그램이 막혀 있으면 시험 전송에서 "연결하지 못했습니다"가 나옵니다. 전송에 실패하면 1분마다 다시 시도하고, 마지막 오류를 화면에 보여 줍니다.
- 데스크톱 프로그램의 **이 PC 혼자 쓰기** 모드에서는 프로그램이 켜져 있을 때만 보냅니다.

## 7-2. 팀즈(Teams) 채널 아침 요약 (관리자)

텔레그램 대신(또는 함께) 회사 팀즈 채널에 같은 요약을 카드로 올릴 수 있습니다. 관리 › **알림 (텔레그램 · 팀즈)** 아래쪽 '팀즈 채널로도 보내기'에서 설정합니다.

1. 팀즈에서 받을 채널 이름 옆 **···** → **워크플로** → **웹훅 요청을 받으면 채널에 게시** 를 고릅니다.
2. 흐름 이름과 팀 · 채널을 확인하고 만듭니다. 마지막 화면의 **URL 복사**를 누릅니다.
3. QIS 관리 화면의 '웹훅 주소'에 붙여 넣고 저장 → **시험 카드 보내기** → 채널에 카드가 뜨면 **자동 전송 켜기**.
4. 보낼 시각 · 주말 · 세부 내용 설정은 텔레그램과 같이 씁니다.

- 옛 '수신 웹훅(Incoming Webhook)' 앱의 `webhook.office.com` 주소는 2026년 5월에 종료되어 QIS가 받지 않습니다. 반드시 워크플로로 만든 주소를 쓰세요.
- '워크플로' 메뉴가 안 보이면 회사 M365 관리자가 Power Automate(워크플로) 앱을 막아 둔 것입니다. IT에 요청하세요.
- 웹훅 주소는 비밀번호와 같습니다(주소를 아는 누구나 그 채널에 글을 올릴 수 있음). 서버 설정 파일(qis.json)에만 저장되고 화면·이력에는 나오지 않습니다.

## 8. 보안 수칙

- 비밀번호는 본인만 사용하고 공유하지 않습니다. 모든 작업은 **본인 이름으로 변경 이력에 남습니다.**
- 공용 PC에서는 사용 후 반드시 **로그아웃**합니다.
- QIS 자료(통보서 · 사진 · 엑셀 파일)를 외부로 보낼 때는 받는 사람을 확인합니다.

## 9. 자주 묻는 질문

**Q. 개인 QIS(HTML 파일)는 이제 안 쓰나요?**
네. 서버로 옮긴 뒤에는 서버 QIS에만 입력합니다. 두 곳에 입력하면 내용이 서로 달라집니다.

**Q. 잘못 고치거나 지운 기록을 되돌릴 수 있나요?**
모든 변경의 이전 값과 이전 버전이 서버에 남아 있습니다. 관리자가 변경 이력에서 확인해 되돌릴 수 있습니다.

**Q. 집이나 출장지에서 접속할 수 있나요?**
사내망 전용입니다. 회사 VPN으로 접속하면 쓸 수 있습니다(회사 정책에 따름).

**Q. 화면이 이상하거나 예전 화면이 보여요.**
Ctrl+F5(강력 새로 고침)를 누르세요. 계속되면 관리자에게 화면 캡처와 함께 알리세요.
