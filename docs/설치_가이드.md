# QIS 서버 설치 가이드 (관리자용)

한 대의 PC에 QIS 서버를 설치해 켜 두면, 품질팀은 각자 PC의 브라우저로 그 서버 주소에 접속해 사용합니다.
이 문서는 서버를 설치하고 운영하는 **관리자**를 위한 안내입니다. 팀원은 [사용 가이드](사용_가이드.md)만 보면 됩니다.

## 1. 어디에 설치하나

| 단계 | 설치 위치 | 비고 |
|---|---|---|
| 시험 | 담당자 회사 노트북 | 혼자 써 보며 기존 데이터 · 화면 확인. 접속 주소 `http://localhost:8080` |
| 팀 운영 | 늘 켜져 있는 PC 또는 IT 가상 서버 | 노트북은 꺼지거나 이동하면 팀 전체가 접속 불가 → 맞지 않음 |

**서버 PC 권장 사양**

| 항목 | 권장 |
|---|---|
| CPU | 4코어 |
| 메모리 | 8GB |
| 디스크 | 여유 200GB (첨부 포함) |
| 운영체제 | Windows 10/11 또는 Windows Server |
| 소프트웨어 | Python 3.11 이상 |

## 2. 설치 순서

### 2-1. 프로그램 받기
- 방법은 둘 중 하나입니다.
  - GitHub `qis-server` 저장소에서 **Code → Download ZIP**을 받습니다.
  - 전달받은 `qis-server.zip`을 씁니다.
- 서버 PC의 `D:\QIS` 같은 폴더에 압축을 풉니다.
- 폴더 경로에는 **한글과 공백이 없는 편이 안전**합니다.

### 2-2. Python 설치
- [python.org](https://www.python.org/downloads/)에서 Python 3.11 이상을 받아 설치합니다.
- 설치 첫 화면에서 **Add python.exe to PATH**를 꼭 체크하세요.
- 회사 PC에 프로그램을 설치하는 것이므로, IT 승인이 필요하면 이 단계에서 받습니다.

### 2-3. install.bat 실행
- `qis-server\scripts\windows\install.bat`을 더블클릭합니다.
- 필요한 프로그램(FastAPI · uvicorn)이 자동으로 설치되고, 마지막에 **첫 관리자 아이디 · 이름 · 비밀번호**를 묻습니다.
- 비밀번호는 8자 이상, 영문과 숫자를 모두 넣어야 하며, 아이디를 포함할 수 없습니다.

> **인터넷이 막힌 PC라면**
> 1. 인터넷 되는 PC에서 `qis-server` 폴더로 가서 `pip download -r requirements.txt -d wheels`를 실행합니다.
> 2. 만들어진 `wheels` 폴더를 서버 PC의 `qis-server` 안에 복사합니다.
> 3. `install.bat`을 실행하면 `wheels` 폴더에서 자동으로 설치합니다.

### 2-4. 서버 실행
- `scripts\windows\run.bat`을 실행합니다.
- 검은 창이 떠 있는 동안 서버가 동작합니다. **창을 닫으면 서버가 멈춥니다.**
- 브라우저(Edge · Chrome)에서 `http://localhost:8080`으로 접속해 관리자로 로그인합니다.

### 2-5. 기존 QIS 데이터 가져오기
1. 지금 쓰는 개인 QIS에서 **설정 › 데이터 · 백업 › 지금 백업**을 눌러 JSON 파일(사진 포함)을 받습니다.
2. 서버 QIS 상단의 **관리**를 누르고 **백업 · 데이터 › 기존 QIS 데이터 가져오기**에서 그 파일을 선택합니다.
3. 불량 · NCR · 협력사 · 부품 · 입고 · 사진 · 첨부가 모두 들어옵니다.

- 서버에 기록이 이미 있으면 **지금 데이터를 비우고 바꿀지** 묻습니다. 바꾸기 전에 DB 백업(`backup/db/qis_…_before_import.sqlite`)을 자동으로 받아 두므로 되돌릴 수 있습니다(복원은 2-8). 사용자 계정 · 변경 이력은 남습니다. 가져온 뒤에는 개인 QIS 대신 서버 QIS에 입력하세요.
- **데이터 비우기 (시험용):** 같은 화면의 **모든 기록 비우기**로 처음 상태로 만들 수 있습니다. 확인 문구 "비우기"를 입력해야 하고, 비우기 전 DB 백업(`…_before_reset.sqlite`)을 자동으로 받습니다. 정식 사용 중에는 쓰지 마세요.
- 명령으로 할 수도 있습니다: `.venv\Scripts\python -m qis import 백업파일.json`

### 2-6. 팀원 계정 만들기
- **관리 › 사용자**에서 아이디 · 이름 · 역할 · 임시 비밀번호를 넣고 **추가**합니다. **자동 생성** 버튼으로 임시 비밀번호를 만들 수 있습니다.
- 팀원에게 **접속 주소 · 아이디 · 임시 비밀번호**를 전달합니다. 처음 로그인하면 각자 본인 비밀번호로 바꾸게 됩니다.

| 역할 | 할 수 있는 일 | 권장 대상 |
|---|---|---|
| 조회 | 보기 · 검색 · 출력 | 관련 부서, 경영진 |
| 작성 | 불량 · NCR · 귀책 · RCA · 입고 등록 · 수정, 협력사 · 부품 추가 · 수정 | 품질팀 실무자 |
| 관리자 | 작성 + 기준정보 삭제, BOM 교체, 설정, 사용자 · 변경 이력 · 백업 관리 | QIS 담당자 1~2명 |

### 2-7. 다른 PC에서 접속 열기 (방화벽)
1. 서버 PC에서 **명령 프롬프트를 관리자 권한으로** 열고 다음을 실행합니다.
   ```
   netsh advfirewall firewall add rule name="QIS" dir=in action=allow protocol=TCP localport=8080
   ```
2. 팀원 PC에서 `http://서버PC이름:8080`으로 접속합니다.
   - 서버 PC 이름은 Windows **설정 › 시스템 › 정보 › 장치 이름**에서 확인합니다.
   - 이름으로 안 되면 IP 주소로 접속합니다(예: `http://10.1.2.34:8080`). IP는 명령 프롬프트에서 `ipconfig`로 확인합니다.
- 회사 방화벽 정책상 IT가 해 줘야 할 수 있습니다.
- 사내망 밖이나 휴대폰에서 접속하려면 회사 VPN 정책을 따릅니다(IT 협의).
- 혼자만 쓰면서 핸드폰으로도 보려면 → [Tailscale로 나만 쓰기](Tailscale_개인사용.md) (이 경우 방화벽은 열지 않습니다)

### 2-8. 자동 실행 · 백업 폴더
- **PC를 켤 때 자동 실행**: `scripts\windows\register_startup.bat`을 **관리자 권한으로** 실행합니다. 로그인하지 않아도 PC가 켜지면 서버가 시작됩니다.
  - 해제: `schtasks /delete /tn "QIS Server" /f`
  - 실행 기록은 `data\server.log`에 남습니다.
- **백업 폴더를 서버 PC 밖으로**:
  1. `data\qis.json`을 메모장으로 열어 `"backup_dir"`에 네트워크 드라이브 경로를 넣습니다. 예: `"backup_dir": "\\\\fileserver\\QIS백업"`
  2. 서버를 다시 시작합니다.

## 3. HTTPS (권장)

사내 인증서가 있으면 설정만으로 HTTPS로 실행합니다.

1. 인증서 파일(`.crt`/`.pem`)과 키 파일(`.key`)을 서버 PC에 둡니다.
2. `data\qis.json`에 경로를 넣습니다.
   ```json
   "port": 8443,
   "ssl_certfile": "D:\\QIS\\cert\\qis.crt",
   "ssl_keyfile": "D:\\QIS\\cert\\qis.key"
   ```
3. 방화벽에서 8443 포트를 열고, 서버를 다시 시작합니다.
4. 접속 주소: `https://서버PC이름:8443`

인증서 발급은 IT에 요청합니다. IIS 등 기존 웹 서버 뒤에 두는 방식도 가능합니다.

## 4. 운영

| 할 일 | 방법 |
|---|---|
| 서버 상태 확인 | 브라우저에서 `http://서버PC이름:8080/healthz` → `{"ok":true}` |
| 지금 백업 | 관리 › 백업 · 데이터 › **지금 백업** (또는 `python -m qis backup`) |
| 자동 백업 확인 | 관리 › 백업 · 데이터에서 마지막 백업 시각 · 오류 확인. 매일 새벽 2시 이후 1회 |
| 변경 이력 조회 | 관리 › 변경 이력 — 기간 · 종류 · 사용자 · NCR 번호로 검색, CSV 내려받기 |
| 사용자 잠김 해제 | 5회 실패하면 10분 뒤 자동 해제. 급하면 관리 › 사용자 › 비밀번호 초기화 |
| 퇴사 · 부서 이동 | 관리 › 사용자 › **사용 중지** (기록과 이력은 그대로 남음) |
| 관리자 비밀번호 분실 | 서버 PC에서 `.venv\Scripts\python -m qis resetpw 아이디` |

### 업데이트 (새 버전 받기)
1. 서버를 멈춥니다. `run.bat` 창을 닫거나, 자동 실행이면 작업 관리자에서 python을 끝냅니다.
2. 새 버전 ZIP의 내용으로 `qis-server` 폴더를 덮어씁니다. **`data` 폴더는 덮어쓰지 않습니다.**
3. `install.bat`을 다시 실행하고(이미 있는 관리자 계정은 그대로), 서버를 시작합니다.

### 복원 (서버 PC 고장 · 잘못된 대량 수정)
1. 서버를 멈춥니다. 자동 시작으로 돌고 있으면 관리자 권한 명령 창에서 `schtasks /end /tn "QIS Server"`를 실행합니다.
2. qis-server 폴더에서 명령 창을 열고 아래를 실행합니다. 백업 파일을 검사해 건수를 보여 주고, `y`를 입력하면 복원합니다.
   ```
   .venv\Scripts\python -m qis restore "백업폴더\db\qis_YYYYMMDD_HHMM.sqlite"
   ```
   - 지금 DB(`qis.db` · `qis.db-wal` · `qis.db-shm`)는 `data\restore_before_시각\`에 그대로 보관됩니다.
   - 백업 폴더 `files\`에서 지금 없는 첨부만 채웁니다.
3. 서버를 시작하고, 사용자들에게 화면을 새로고침(F5)하라고 알립니다.

> `data\qis.db`만 손으로 바꾸지 마세요. 서버가 강제 종료된 뒤에는 `qis.db-wal`에 남은 최근 변경이 복원한 파일 위에 다시 적용되어 복원이 되지 않습니다.

서버를 당분간 쓸 수 없으면, 백업 폴더의 `json\QIS_서버백업_날짜.json`을 개인 QIS 화면에서 **설정 › 데이터 · 백업 › 백업으로 교체**로 열어 조회할 수 있습니다.

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| install.bat에서 "Python이 없습니다" | Python 설치 때 *Add python.exe to PATH*를 체크했는지 확인. 다시 설치 |
| pip 설치 실패 | 회사 네트워크가 막힌 경우 → 2-3의 wheels 폴더 방법 |
| 다른 PC에서 접속 안 됨 | 서버가 실행 중인지(`/healthz`), 방화벽 8080 허용, PC 이름 대신 IP로 시도 |
| "포트가 사용 중" 오류 | `data\qis.json`의 `port`를 다른 번호(예: 8081)로 바꾸고 방화벽도 같은 번호로 |
| 화면이 예전 그대로 | 브라우저에서 Ctrl+F5 (강력 새로 고침) |
| 자동 백업이 안 됨 | 관리 › 백업 · 데이터의 오류 메시지 확인. 네트워크 드라이브 경로 · 권한 확인 |
