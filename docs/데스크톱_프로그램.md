# QIS 데스크톱 프로그램 (맥 · 윈도우)

QIS 서버판을 **더블클릭으로 여는 프로그램** 하나로 묶은 것입니다. 화면 · 기능 · 데이터 형식은 서버판과 같습니다.

- 파이썬 · 브라우저를 따로 설치하지 않아도 됩니다.
- 프로그램을 열면 QIS 창이 뜨고, 창을 닫으면 저장을 마무리하고 끝납니다.
- 맥(Apple Silicon)은 `QIS.app`, 윈도우는 `QIS.exe` 입니다.

## 1. 설치

### 받기

GitHub 저장소의 **Releases**에서 최신 버전을 엽니다. 아래 파일 중 내 PC에 맞는 것을 받습니다.

| PC | 권장 (설치 프로그램) | 또는 (압축 파일) |
|---|---|---|
| 윈도우 10 · 11 | **`QIS-Setup.exe`** — 더블클릭 → 다음 → 설치. 관리자 권한 없이 내 계정에 설치됩니다 | `QIS-windows.zip` → `QIS` 폴더 (안에 `QIS.exe`) |
| 맥 (M1 · M2 · M3 · M4 …) | **`QIS-mac.dmg`** — 열어서 `QIS.app`을 Applications 폴더로 끌어 놓기 | `QIS-mac.zip` → `QIS.app` |

설치 프로그램으로 설치하면 시작 메뉴 · 바탕 화면 바로 가기가 생기고, 새 버전도 같은 설치 프로그램을 실행하면 덮어씁니다. 제거는 **설정 › 앱**에서 하고, 제거해도 데이터 폴더(`%LOCALAPPDATA%\QIS`)는 남습니다.

> 코드 서명 인증서가 없는 빌드는 윈도우 SmartScreen · 맥 Gatekeeper 경고가 뜹니다(아래 '처음 열기'). 서명 인증서를 넣고 빌드하면(관리자 안내 참고) 경고 없이 열립니다.

### 맥: 처음 열기

1. `QIS-mac.zip`을 더블클릭해 압축을 풉니다.
2. `QIS.app`을 **응용 프로그램** 폴더로 끌어 옮깁니다.
3. `QIS.app`을 **우클릭(또는 control+클릭) › 열기**를 누릅니다. 경고 창에서 다시 **열기**를 누릅니다.
   - 회사 인증서로 서명하지 않은 프로그램이라 처음 한 번 이렇게 엽니다. 그다음부터는 더블클릭으로 열립니다.
4. 경고 창에 **열기** 버튼이 없으면(최신 macOS):
   1. 경고 창에서 **완료**를 누릅니다. **휴지통으로 이동은 누르지 마세요.**
   2. **시스템 설정 › 개인정보 보호 및 보안**을 엽니다. 아래쪽에서 `QIS`의 **그래도 열기**를 누릅니다.
   3. 암호(또는 Touch ID)를 넣고 다시 엽니다.
5. 그래도 안 열리면 터미널에서 한 번만 실행합니다.
   ```
   xattr -dr com.apple.quarantine /Applications/QIS.app
   ```

### 윈도우: 처음 열기

**설치 프로그램(`QIS-Setup.exe`)을 쓰는 경우**: 더블클릭 → "Windows의 PC 보호" 창이 뜨면 **추가 정보 › 실행** → 다음 → 설치. 끝나면 바로 실행됩니다. 아래 2~5번은 압축 파일로 설치할 때만 해당합니다.

1. `QIS-windows.zip`을 **우클릭 › 압축 풀기**로 풉니다. 압축 파일 안에서 바로 실행하지 마세요.
2. 풀린 `QIS` 폴더를 원하는 곳에 둡니다. 예: `C:\QIS`
   - 폴더 안의 `_internal` 폴더도 함께 있어야 합니다. `QIS.exe`만 따로 옮기지 마세요.
3. `QIS.exe`를 더블클릭합니다. 바탕 화면 바로 가기를 만들어 두면 편합니다(`QIS.exe` 우클릭 › 바로 가기 만들기).
4. **"Windows의 PC 보호"** 파란 창이 뜨면 **추가 정보 › 실행**을 누릅니다.
5. **"Failed to resolve Python.Runtime.Loader.Initialize" 오류 창**이 뜨면, 받은 zip에 붙은 "인터넷에서 받은 파일" 표시 때문입니다. 새 버전은 프로그램이 시작할 때 스스로 이 표시를 지웁니다. 이전 버전이거나 그래도 뜨면 아래 순서로 합니다.
   - 받은 `QIS-windows.zip`을 **우클릭 › 속성 › 아래쪽 "차단 해제" 체크 › 확인** → 다시 압축 풀기
   - 그래도 같으면 회사 보안 프로그램이 DLL을 막고 있는 것입니다. IT에 QIS 폴더 예외 등록을 요청합니다.
6. 창이 하얗게 비어 있으면 Microsoft Edge WebView2가 없는 PC입니다. Microsoft 사이트에서 **WebView2 런타임**을 설치합니다. 윈도우 10 · 11은 대부분 이미 있습니다.

### 처음 실행: 사용 방식 고르기

처음 열면 두 가지 중 하나를 고릅니다. 나중에 메뉴 **설정 › 사용 방식 바꾸기**에서 바꿀 수 있고, 바꿔도 데이터는 그대로입니다.

## 2. 두 가지 사용 방식

| | 🖥 이 PC 혼자 쓰기 | 🏢 사내 서버로 쓰기 |
|---|---|---|
| 로그인 | 없음 (바로 시작) · 원하면 **비밀번호 잠금** | 아이디 · 비밀번호 |
| 접속 | 이 PC에서만 (다른 PC · 핸드폰 차단) | 같은 사내망 · Wi-Fi의 다른 PC · 핸드폰 |
| 권한 | 나 혼자 (관리자) | 조회 · 작성 · 관리자 |
| 처음에 넣는 것 | 내 이름 (담당자 · 변경 이력에 남는 이름) | 관리자 아이디 · 이름 · 비밀번호 · 포트(보통 8080) |
| 어울리는 경우 | 개인 업무 · 시험 | 품질팀이 함께 쓰기 |

### 혼자 쓰기

- 프로그램이 이 PC 안에서만 열리는 주소를 씁니다. 다른 PC에서는 접속할 수 없습니다.
- 로그인 · 로그아웃 · 비밀번호 버튼은 보이지 않습니다.
- 변경 이력에는 처음에 넣은 이름으로 남습니다.
- **비밀번호로 잠그기**: 사용 방식 고르기 화면에서 켜면 프로그램을 열 때 로그인 화면이 뜹니다(자리 비움 · 공용 PC). 아이디는 `local`로 고정되어 비밀번호만 입력하고, 로그아웃 · 비밀번호 바꾸기 버튼도 생깁니다. 한 번 로그인하면 24시간 안에 다시 열 때는 묻지 않습니다. 비밀번호를 잊으면 메뉴 **설정 › 사용 방식 바꾸기**에서 새로 정하면 됩니다(데이터는 그대로). 잠금을 끄면 비밀번호는 지워지고 다시 자동 입장합니다.

### 사내 서버로 쓰기

- 시작하면 **다른 PC · 핸드폰 접속 주소**가 표시됩니다. 예: `http://192.168.0.10:8080`
  - 메뉴 **설정 › 접속 주소 보기**로 다시 볼 수 있습니다.
- 팀원은 브라우저(Edge · Chrome · 핸드폰)로 그 주소에 접속해 로그인합니다. 팀원 PC에는 프로그램을 설치하지 않아도 됩니다.
- 사용자 추가 · 변경 이력은 화면 위쪽 **관리** 버튼에서 합니다. 서버판과 같습니다.
- **이 PC가 켜져 있고 QIS 창이 열려 있는 동안만** 다른 사람이 접속할 수 있습니다.
  - 창을 닫으려 하면 "사내 서버도 꺼집니다" 확인 창이 뜹니다. 최근 15분 안에 다른 PC · 핸드폰에서 쓴 사용자가 있으면 그 수도 알려 줍니다.
  - 절전 모드로 들어가도 접속이 끊깁니다. 사내 서버로 쓰는 동안은 절전을 꺼 두세요.
- 방화벽:
  - 윈도우: 처음 시작할 때 뜨는 Windows 방화벽 창에서 **액세스 허용**을 누릅니다.
  - 맥: "들어오는 네트워크 연결을 허용할까요?" 창에서 **허용**을 누릅니다.
- "포트를 다른 프로그램이 쓰고 있습니다"가 나오면 사용 방식 화면에서 포트를 `8090`처럼 바꿉니다.
  - 기존 서버판(검은 창)이 켜져 있으면 그 창을 먼저 닫습니다.
- **사내 서버 모드 HTTPS (권장):** 기본은 `http`라서 사내망에서 아이디 · 비밀번호 · 기록 내용이 암호화되지 않고 오갑니다. 접속 주소 화면에도 경고가 나옵니다.
  1. IT에 이 PC 이름(또는 IP)용 인증서를 요청합니다. 인증서 파일(`.crt`/`.pem`)과 키 파일(`.key`)을 받습니다.
  2. 두 파일을 데이터 폴더 안 `cert/` 폴더에 둡니다(메뉴 **파일 › 데이터 폴더 열기**).
  3. 데이터 폴더의 `qis.json`에 경로를 적습니다.
     ```json
     "ssl_certfile": "C:\\Users\\이름\\AppData\\Local\\QIS\\cert\\qis.crt",
     "ssl_keyfile": "C:\\Users\\이름\\AppData\\Local\\QIS\\cert\\qis.key"
     ```
  4. 프로그램을 다시 엽니다. 접속 주소가 `https://…`로 바뀝니다. 혼자 쓰기 모드에는 영향이 없습니다.
  - 키 파일은 다른 곳에 복사하거나 메일로 보내지 마세요.
- 여러 사람이 매일 쓰는 정식 서버는 서버 PC에 서버판을 설치하는 쪽이 안정적입니다. [설치 가이드](설치_가이드.md)를 보세요. 자동 시작 · HTTPS · 네트워크 드라이브 백업을 쓸 수 있습니다.

## 3. 데이터 위치 · 백업 · 옮기기

### 데이터 위치

데이터는 프로그램 폴더가 아니라 **사용자 데이터 폴더**에 저장됩니다. 프로그램을 새 버전으로 바꾸거나 지워도 데이터는 남습니다.

| PC | 데이터 폴더 |
|---|---|
| 맥 | `~/Library/Application Support/QIS` |
| 윈도우 | `%LOCALAPPDATA%\QIS` (예: `C:\Users\이름\AppData\Local\QIS`) |

> **윈도우 1.3.5 이하에서 쓰던 데이터:** 예전에는 `AppData\Roaming\QIS`에 두었습니다. 회사 PC가 로밍 프로필을 쓰면 이 폴더가 로그온 · 로그오프 때 네트워크로 동기화되어 DB가 손상될 수 있어 `Local`로 옮겼습니다.
> - 새 버전을 처음 열면 **자동으로 옮깁니다.** `qis.json`에 적힌 예전 폴더 경로(인증서 등)도 새 경로로 바뀝니다.
> - 다른 드라이브라 복사로 옮긴 경우에는 원본을 지우지 않고 `Roaming\QIS_이전됨_날짜` 이름으로 남깁니다. 새 버전에서 기록이 잘 보이면 지워도 됩니다.
> - 예전 버전 QIS가 열려 있으면 옮기지 않고 예전 폴더를 그대로 씁니다. 예전 창을 닫고 다시 열면 옮깁니다.
> - 무엇을 했는지는 `logs/desktop.log`에 남습니다. 옮긴 뒤에 예전 버전 프로그램을 열면 빈 화면이 나오니, 예전 버전은 지우세요.

메뉴 **파일 › 데이터 폴더 열기**를 누르면 바로 열립니다. 안에는 다음이 있습니다.

| 이름 | 내용 |
|---|---|
| `qis.db` | 기록 · 사용자 · 변경 이력 (DB 파일 하나) |
| `files/` | 첨부 (사진 · 문서) |
| `backup/` | 자동 백업 |
| `qis.json` · `desktop.json` | 설정 |
| `logs/` | 프로그램 기록 (문제가 생겼을 때 확인) |

### 백업

- **자동 백업**은 하루 한 번 합니다. 새벽 2시 이후 프로그램이 처음 켜져 있을 때 `backup/` 폴더에 저장합니다.
  - DB 사본(최근 30개) · 기록 JSON · 첨부 사본이 저장됩니다. 서버판과 같은 방식입니다.
- **지금 백업:** 메뉴 **파일 › 지금 백업**
- **백업 파일 하나로 저장:** 설정 › 데이터 › 백업 내려받기
  - 사진 포함 JSON을 원하는 위치에 저장합니다. 외장 디스크 · 회사 공유 폴더에 따로 보관하세요.
- **백업 폴더 위치 바꾸기:** 데이터 폴더의 `qis.json`에서 `"backup_dir"`에 다른 폴더(예: 회사 공유 폴더)를 적고 프로그램을 다시 엽니다.
- 이 PC가 고장 나도 복구하려면 `backup/` 폴더나 백업 파일을 **다른 곳에 정기적으로 복사**해 두세요.

### 복원

1. 메뉴 **파일 › 백업에서 복원**을 누릅니다.
2. `backup/db/qis_날짜_시각.sqlite` 중 하나를 고릅니다.
3. 기록 건수를 확인하고 **확인**을 누릅니다.

지금 데이터는 지우지 않습니다. 데이터 폴더의 `restore_before_날짜` 폴더에 보관합니다.

### 기존 데이터 가져오기

| 가져올 것 | 메뉴 | 고를 것 |
|---|---|---|
| 개인판(HTML) 백업 | **파일 › 가져오기: 개인판 HTML 백업 (JSON)** | `QIS_최신백업.json` · `QIS_data.json` · 서버 백업 JSON |
| 서버판 데이터 | **파일 › 가져오기: 서버판 data 폴더** | 서버판의 `data` 폴더 (`qis.db`가 있는 폴더) |

- 이미 기록이 있으면 바꿀지 먼저 묻습니다. 지금 데이터는 `restore_before_날짜` 폴더에 보관합니다.
- 화면 위쪽 **관리 › 백업 · 데이터**에서도 개인판 백업을 가져올 수 있고(기록이 있으면 비우고 바꿀지 물음), **모든 기록 비우기**로 시험 데이터를 처음 상태로 돌릴 수 있습니다. 둘 다 바꾸기 전 DB 백업을 자동으로 받습니다.
- **개인판 백업:** 사진 포함 백업이면 사진도 함께 들어옵니다. 사용자 계정은 그대로 유지됩니다.
  - 개인 QIS 백업 파일은 두 종류입니다. `백업/QMS_백업_날짜_시각.json`("지금 백업" · 날짜별 자동 백업)에는 사진 본체가 들어 있고, 1분마다 저장되는 `QMS_data.json`에는 사진 **정보만** 있습니다(본체는 `사진·첨부` 폴더의 파일). 사진까지 옮기려면 앞의 파일을 쓰세요.
  - 사진 정보만 든 파일로 가져왔다면(사진을 누르면 "저장된 사진을 찾을 수 없습니다"): **관리 › 백업 · 데이터 › 빠진 사진 채우기**에서 사진 포함 백업 파일을 고르거나, 개인 QIS의 QIS 폴더(사진·첨부 폴더)를 통째로 골라 파일 이름으로 채웁니다. 기록은 그대로 두고 사진만 들어갑니다.
- **서버판 data 폴더**
  - 기록 · 첨부 · 사용자 · 변경 이력이 모두 들어옵니다. 원본 폴더는 바꾸지 않습니다.
  - 가져오기 전에 기존 서버판(검은 창)을 꼭 닫으세요.
  - 사내 서버 모드에서는 기존 서버판의 아이디 · 비밀번호로 로그인합니다.

### 다른 PC로 옮기기

1. 이전 PC에서 QIS를 닫습니다.
2. 데이터 폴더(`QIS` 폴더 전체)를 USB · 공유 폴더로 복사합니다.
3. 새 PC에 프로그램을 설치하고 한 번 열었다가 닫습니다.
4. 새 PC의 데이터 폴더를 복사해 온 것으로 바꿉니다.

맥 ↔ 윈도우 사이에도 그대로 옮길 수 있습니다.

간단히 하려면 이전 PC에서 백업 파일(JSON)을 저장하고, 새 PC에서 **가져오기: 개인판 HTML 백업**으로 넣어도 됩니다. 이 방법에서는 사용자 계정과 변경 이력은 옮겨지지 않습니다.

### 안전 장치

- **첨부 열어보기는 보기 전용 형식만:** PDF · 그림 · 글자(txt · csv)만 PC의 기본 프로그램으로 바로 엽니다. 그 밖의 파일(엑셀 · 실행 파일 등)은 저장할 위치를 묻습니다. 열어 본 첨부의 임시 사본은 다음 실행 때 지웁니다.
- **QIS 밖의 페이지 차단:** 프로그램 창이 QIS가 아닌 주소로 이동하면 QIS 화면으로 되돌립니다. 프로그램 기능(파일 저장 · 열기 등)은 QIS 화면에서만 동작합니다.
- **로그인 보호:** 계정마다 연속 실패 시 잠금에 더해, 한 PC(접속 주소)에서 실패가 많으면 그 PC만 잠시 막습니다.
- **혼자 쓰기 로그인:** 프로그램을 닫으면 로그인이 끝나고, 다시 열 때 새로 들어갑니다. 창에 로그인이 저장되어 남지 않습니다.

- **두 번 열기 방지:** QIS가 이미 열려 있으면 두 번째 창은 "이미 열려 있습니다"를 보여 주고 열리지 않습니다. 같은 데이터를 두 프로그램이 동시에 고치지 않게 하려는 것입니다.
- **비정상 종료 검사:** 정전 · 강제 종료 뒤 다시 열면 먼저 DB를 검사합니다. 문제가 있으면 **최근 백업으로 복원**을 권합니다.
- **창을 닫을 때:** 아직 보내지 않은 변경을 저장하고 닫습니다. 작성 중인 창이 열려 있으면 그래도 닫을지 묻습니다.
- **맥의 폴더 선택 창 멈춤 문제:** 프로그램은 브라우저의 폴더 선택 기능을 쓰지 않습니다. 백업은 데이터 폴더의 `backup/`에 자동으로 저장합니다. 파일을 고를 때는 맥 · 윈도우 기본 창을 씁니다.

## 4. 업데이트

1. Releases에서 새 버전 zip을 받습니다.
2. QIS를 닫습니다.
3. 프로그램을 새 것으로 바꿉니다.
   - 맥: 응용 프로그램 폴더의 `QIS.app`을 새 `QIS.app`으로 바꿉니다.
   - 윈도우: `QIS` 폴더를 새 폴더로 통째로 바꿉니다. `_internal` 폴더까지 바꿔야 합니다.
4. 처음 한 번은 다시 **우클릭 › 열기**(맥)나 **추가 정보 › 실행**(윈도우)이 필요할 수 있습니다.

데이터는 데이터 폴더에 있으므로 그대로 이어집니다. 업데이트 전에 **파일 › 지금 백업**을 한 번 해 두면 안심입니다.

### (관리자) 코드 서명 — 경고 없이 열리게 하려면

인증서를 GitHub 시크릿에 넣어 두면 빌드가 자동으로 서명합니다. 없으면 서명 단계는 건너뜁니다.

| OS | 필요한 것 | 시크릿 이름 |
|---|---|---|
| 윈도우 | 코드 서명 인증서 .pfx (OV 또는 EV, 연 수십만 원) | `WINDOWS_CERT_PFX_BASE64`(pfx 를 base64 로), `WINDOWS_CERT_PASSWORD` |
| 맥 | Apple Developer Program(연 $99) 의 Developer ID Application 인증서 .p12 + 공증용 앱 암호 | `APPLE_CERT_P12_BASE64`, `APPLE_CERT_PASSWORD`, `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_APP_PASSWORD` |

윈도우는 `QIS.exe` · 설치 프로그램 · 제거 프로그램에 서명(타임스탬프 포함)하고, 맥은 앱 서명 → Apple 공증 → 스테이플까지 합니다. 윈도우 OV 인증서는 서명 직후에도 SmartScreen 평판이 쌓일 때까지(보통 몇 주 · 다운로드 수) 경고가 남을 수 있고, EV 는 바로 사라집니다.

### (관리자) 새 버전 릴리스 만들기

릴리스 파일은 GitHub Actions가 맥 · 윈도우에서 자동으로 만듭니다. 방법은 둘 중 하나입니다.

- **방법 1:** GitHub › **Actions › desktop › Run workflow**를 누릅니다. 버전에 `v1.1.0`처럼 적고 실행합니다.
- **방법 2:** GitHub › **Releases › Draft a new release**에서 새 태그(예: `v1.1.0`)를 만들고 **Publish**합니다.

약 15분 뒤 그 릴리스에 `QIS-Setup.exe` · `QIS-windows.zip` · `QIS-mac.dmg` · `QIS-mac.zip`이 올라갑니다. 윈도우 빌드는 설치 프로그램을 CI 에서 실제로 조용히 설치 → 실행 점검 → 제거까지 해 봅니다. PR마다 두 OS에서 빌드 · 실행 점검이 자동으로 돌아갑니다.

## 5. 알아 둘 제약

- **코드 서명 없음:** 그래서 처음 열 때 맥 · 윈도우 경고가 나옵니다. 위의 처음 열기 방법대로 엽니다.
  - 회사에서 Apple Developer ID · 윈도우 코드 서명 인증서를 마련하면 경고 없이 열리게 바꿀 수 있습니다.
- **맥은 Apple Silicon(M 칩) 전용**입니다. 2020년 이전 Intel 맥에서는 서버판(`start-mac.command`)을 쓰세요.
- **보고서 · 인쇄 미리보기**는 프로그램 안의 새 창으로 열립니다. 인쇄 창에서 PDF로 저장할 수 있습니다.
- **첨부(PDF · 사진) 열기**는 PC의 기본 프로그램으로 엽니다(미리보기 · 사진 앱 등).
- **문제가 생기면:** 데이터 폴더의 `logs/desktop.log`를 확인합니다. 담당자에게 보낼 때도 이 파일을 함께 보냅니다.
