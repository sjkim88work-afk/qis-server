# QIS 데스크톱 프로그램 (QIS.app · QIS.exe)

파이썬 · 브라우저를 설치하지 않고 **더블클릭 한 번**으로 여는 QIS입니다. 화면과 기능은 서버판과 같고, 프로그램 안에 서버가 들어 있어 창을 열면 켜지고 닫으면 꺼집니다.

| | 서버판 (`start-mac.command` · `start-windows.bat`) | 데스크톱 프로그램 |
|---|---|---|
| 설치 | Python 3.11 이상 필요 | 압축만 풀면 됨 |
| 실행 | 명령 창 + 브라우저 | 프로그램 창 하나 |
| 데이터 위치 | 프로그램 폴더의 `data/` | 사용자 데이터 폴더 (아래) — 프로그램을 바꿔도 유지 |
| 접속 | 사내망 공개 · 로그인 | **이 PC 혼자 쓰기** 또는 **사내 서버로 쓰기** 중 고름 |

## 1. 설치 · 처음 열기

1. GitHub **Releases**에서 내 PC에 맞는 파일을 받습니다.
   - 맥 (Apple Silicon): `QIS-mac.zip`
   - Windows 10/11: `QIS-windows.zip`
2. 압축을 풉니다.
   - 맥: `QIS.app`이 나옵니다. **응용 프로그램** 폴더로 옮기면 Launchpad에서도 열 수 있습니다.
   - Windows: `QIS` 폴더가 나옵니다. 폴더째 원하는 곳(예: `D:\QIS`)에 두고 안의 `QIS.exe`를 엽니다. 바탕화면에 바로 가기를 만들어 두면 편합니다. **폴더 안의 다른 파일을 지우거나 옮기지 마세요.**
3. 처음 열면 **사용 방식**을 묻습니다 (아래 2). 고른 뒤에는 바로 QIS 화면이 열립니다.

### 맥에서 "확인되지 않은 개발자" · "열 수 없음" 경고가 날 때

이 프로그램은 Apple 개발자 서명이 없어 처음 한 번 Gatekeeper가 막습니다. 바이러스가 아니라 서명이 없다는 뜻입니다.

1. Finder에서 `QIS.app`을 **우클릭(또는 control+클릭) › 열기**를 누릅니다.
2. 경고 창에서 다시 **열기**를 누릅니다. (경고에 "열기" 단추가 없으면: **시스템 설정 › 개인정보 보호 및 보안**을 열고 아래쪽 보안 항목의 **그래도 열기**를 누른 뒤 다시 엽니다.)
3. 그다음부터는 더블클릭으로 열립니다.

그래도 열리지 않으면 터미널에서 한 번만 실행합니다 (경로는 `QIS.app`이 있는 곳).

```
xattr -dr com.apple.quarantine /Applications/QIS.app
```

### Windows에서 "Windows의 PC 보호" 파란 창이 뜰 때

코드 서명이 없어서 SmartScreen이 묻는 것입니다. **추가 정보 › 실행**을 누르면 됩니다. 회사 PC에서 실행 자체가 막혀 있으면 전산팀에 `QIS.exe` 허용을 요청하세요.

Windows가 **방화벽 허용**을 묻는 것은 "사내 서버로 쓰기"를 골랐을 때만이며, 다른 PC·핸드폰이 접속하려면 **개인 네트워크**를 허용해야 합니다. "이 PC 혼자 쓰기"는 묻지 않습니다.

## 2. 두 가지 사용 방식

처음 열 때 고르고, 나중에 QIS **설정 › 데이터 · 백업 › 이 PC의 QIS 프로그램 › 바꾸기**에서 바꿀 수 있습니다. 바꿔도 데이터는 그대로입니다.

| | 이 PC 혼자 쓰기 | 사내 서버로 쓰기 |
|---|---|---|
| 로그인 | 없음 — 열면 바로 QIS | 아이디 · 비밀번호 (서버판과 같음) |
| 접속 | 이 PC 안에서만. 다른 PC · 핸드폰 · 사내망에서 접속 불가 | 같은 사내망 PC · 핸드폰에서 접속 (주소는 설정 화면에 표시) |
| 계정 | 프로그램이 로컬 관리자 계정(`local`)을 자동으로 씀. 비밀번호 없음 | 처음 고를 때 관리자 계정을 만들고, 관리 화면에서 팀원 추가 |
| 권한 | 항상 관리자 | 역할별 (조회 · 작성 · 관리자) |
| 쓰임 | 개인 업무 · 노트북 | 팀이 함께 쓰는 공용 PC. 이 PC가 켜져 있고 **QIS 창이 열려 있어야** 다른 사람이 접속됨 |

- "혼자 쓰기"에서도 기록의 **담당자 · 작성자 이름**은 처음 고를 때 넣은 **내 이름**으로 남고, 변경 이력도 그대로 기록됩니다.
- "사내 서버"로 바꾸면 비밀번호 없는 `local` 계정은 꺼집니다(기록은 그대로). 다시 "혼자 쓰기"로 바꾸면 켜집니다.
- 24시간 켜 두는 진짜 서버가 필요하면 서버판([설치 가이드](설치_가이드.md))을 쓰고, 데스크톱 프로그램의 데이터는 아래 "옮기기"로 가져갑니다.

## 3. 데이터 위치 · 백업 · 옮기기

### 데이터 폴더

| PC | 위치 |
|---|---|
| 맥 | `~/Library/Application Support/QIS` (Finder: 이동 › 폴더로 이동 에 붙여넣기) |
| Windows | `%APPDATA%\QIS` (보통 `C:\Users\이름\AppData\Roaming\QIS`) |

QIS **설정 › 데이터 · 백업 › 데이터 폴더 › 폴더 열기**로 바로 열 수 있습니다. 안에는 이런 것이 있습니다.

| 파일 · 폴더 | 내용 |
|---|---|
| `qis.db` | 모든 기록 (DB 파일 하나) |
| `files/` | 사진 · 첨부 |
| `backup/` | 자동 백업 (백업 폴더를 바꾸지 않았을 때) |
| `qis.json` | 설정 (사용 방식 · 포트 · 백업 폴더) |
| `logs/` | 프로그램 기록 — 문제가 생기면 이 폴더를 보냅니다 |
| `restore_before_…/` | 가져오기 · 복원 전에 보관한 이전 DB |
| `열어보기/` | 첨부 · 보고서를 PC 기본 프로그램으로 열 때 잠시 두는 사본 (하루 뒤 자동 정리) |

프로그램이 켜져 있는 동안 `qis.db` 옆에 `qis.db-wal` · `qis.db-shm` 이 생깁니다. **프로그램이 켜진 상태에서 이 파일들을 복사 · 수정하지 마세요.** 끄면 `qis.db` 하나로 정리됩니다.

### 백업

- 서버판과 같이 **매일** 백업 폴더에 DB 사본 · 기록 JSON · 첨부 사본을 남깁니다 (`backup/db`, `backup/json`, `backup/files`). 30개를 보관합니다.
- 백업 폴더는 **다른 드라이브 · 네트워크 폴더(NAS · 공유 폴더)** 를 권장합니다. 설정 › 데이터 · 백업 › **백업 폴더 › 바꾸기**에서 PC의 폴더 선택 창으로 고릅니다 (브라우저의 폴더 선택을 쓰지 않습니다).
- **지금 백업** 단추로 바로 백업할 수 있습니다. 서버판의 `data/backup`과 같은 구조라 서버판 `restore` 명령으로도 복원됩니다.
- `backup/json/QIS_서버백업_날짜.json` 은 개인판 HTML에서 **백업으로 교체**로 열어 볼 수 있습니다.

### 기존 데이터 가져오기

설정 › 데이터 · 백업 › **기존 데이터 가져오기**

| 가져올 것 | 단추 | 조건 |
|---|---|---|
| 개인판 HTML 백업 (`QIS_최신백업.json` · `QIS_data.json` · 서버 내보내기 JSON) | 백업 파일 고르기 | **빈 데이터일 때만** (처음 설치 직후). 사진 포함 백업이면 사진도 들어감 |
| 서버판 `data` 폴더 (`qis.db` 가 있는 폴더) | 서버판 data 폴더 고르기 | 지금 데이터를 **그 내용으로 바꿈**. 지금 DB는 `restore_before_…` 에 보관. 첨부는 없는 것만 복사 |
| 서버 백업 DB (`backup/db/qis_날짜.sqlite`) | 백업 파일 고르기 | 위와 같음 (복원) |

서버판 data 폴더를 가져올 때 그쪽 서버는 꺼 두세요. 가져오는 동안 QIS가 잠깐 다시 시작됩니다.

### 다른 PC로 옮기기

1. 옮길 PC에서 QIS를 **끕니다** (창 닫기).
2. 데이터 폴더(위 표) 전체를 복사해 새 PC의 같은 위치에 둡니다. 새 PC에 QIS를 설치한 적이 없으면 폴더를 새로 만들어 넣으면 됩니다.
3. 새 PC에서 QIS를 엽니다. 설정 · 데이터 · 사진이 그대로 보입니다.

또는 새 PC에서 QIS를 열고 **서버판 data 폴더 고르기**로 옛 PC의 데이터 폴더(`qis.db` 가 있는 폴더)를 고르면 됩니다.

### 데이터 안전 장치

- **하나만 열림**: 같은 데이터 폴더를 두 프로그램(QIS 창 둘, 또는 QIS 창 + 서버판)이 동시에 열 수 없습니다. 두 번째는 "이미 열려 있습니다"만 보여 줍니다.
- **닫을 때 저장 확인**: 아직 저장되지 않은 변경이 있으면 저장을 마친 뒤 닫힙니다. 저장이 안 되면 닫을지 묻습니다.
- **비정상 종료 뒤 검사**: 정전 · 강제 종료 뒤 다시 열면 DB 파일을 검사하고, 손상됐으면 가장 최근 백업으로 복원할지 묻습니다 (지금 파일은 보관).
- 변경 이력 · 이전 버전 보관 · 자동 백업은 서버판과 같습니다.

## 4. 업데이트

데이터는 프로그램 폴더 밖에 있어서 프로그램만 바꾸면 됩니다.

1. QIS를 끕니다.
2. Releases에서 새 zip을 받아 압축을 풉니다.
3. 맥: 새 `QIS.app`으로 기존 것을 덮어씁니다 (처음처럼 우클릭 › 열기 한 번).
   Windows: 기존 `QIS` 폴더를 지우고(또는 이름을 바꿔 두고) 새 `QIS` 폴더를 같은 곳에 둡니다.
4. QIS를 엽니다. 데이터 · 설정은 그대로입니다. 새 버전이 DB 구조를 바꾸면 처음 열 때 자동으로 적용됩니다.

업데이트 전에 **지금 백업**을 한 번 눌러 두면 더 안전합니다.

## 5. 문제 해결

| 증상 | 조치 |
|---|---|
| "QIS가 이미 열려 있습니다" | 열려 있는 QIS 창(Dock · 작업 표시줄)을 쓰세요. 창이 없는데도 나오면 PC를 다시 시작합니다 |
| 창이 하얗게만 보임 · 열리지 않음 | 데이터 폴더의 `logs/qis-desktop.log` 끝부분을 확인합니다. Windows는 **WebView2 런타임**이 필요합니다 (Windows 10/11에는 보통 설치돼 있음, 없으면 Microsoft 사이트에서 "Evergreen" 설치) |
| 맥에서 폴더 선택 창이 오래 멈춤 | 프로그램은 브라우저 폴더 선택 대신 macOS 기본 창을 씁니다. 그래도 느리면 iCloud 드라이브가 아닌 로컬 폴더를 고르세요 |
| 사내 서버 모드인데 다른 PC에서 안 열림 | 설정 화면의 접속 주소 확인 → Windows 방화벽에서 QIS 허용 → 같은 네트워크인지 확인. 이 PC의 QIS 창이 열려 있어야 합니다 |
| 포트가 사용 중 | 사내 서버 모드는 설정한 포트가 막혀 있으면 빈 포트로 켜고 안내합니다. 고정하려면 **바꾸기**에서 다른 포트로 |
| "데이터 파일을 확인해야 합니다" | 가장 최근 백업으로 복원하거나, 터미널에서 서버판 명령으로 복원: `QIS_DATA_DIR="데이터 폴더" python -m qis restore 백업파일.sqlite` (QIS 창은 닫은 상태) |
| 첨부 · 보고서가 안 열림 | 프로그램 창 안에서는 새 창을 띄울 수 없어 PC 기본 프로그램(브라우저 · 사진 · PDF)으로 엽니다. 기본 프로그램이 없으면 `열어보기` 폴더의 파일을 직접 여세요 |

## 6. 개발자 메모

- 코드: `qis/desktop/` (창 `main.py` · 내장 서버 `server.py` · 전용 API `routes.py` · 가져오기 `importer.py` · 잠금 `instance.py`). 화면 `qis/web/index.html` 은 `SRV.desktop` 값으로 데스크톱을 알아보고, 새 창 · 폴더 선택 대신 `/api/desktop/...` 을 씁니다.
- 직접 실행: `pip install -r requirements-desktop.txt` → `python -m qis.desktop` (데이터 폴더는 `QIS_DATA_DIR` 로 바꿀 수 있음).
- 빌드: `python scripts/desktop/make_icons.py` → `pyinstaller --clean scripts/desktop/QIS.spec`. GitHub Actions(`.github/workflows/desktop.yml`)가 PR마다 맥(arm64) · Windows 빌드를 확인하고, `v1.2.0` 같은 태그를 올리면 릴리스에 `QIS-mac.zip` · `QIS-windows.zip` 을 붙입니다.
- 시험: `python -m pytest -q` (`tests/test_desktop.py` — 빈 포트 · 데이터 폴더 · 잠금 · 혼자 쓰기 127.0.0.1 · 로그인 생략 · 종료 정리 · 손상 검사 · 가져오기. 창은 띄우지 않음).
- 코드 서명(Apple Developer ID · Windows Authenticode)은 아직 없습니다. 서명하려면 워크플로의 압축 단계 앞에 서명 · 공증 단계를 넣습니다.
