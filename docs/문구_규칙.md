# QIS 문구 규칙

QIS 화면 문구와 안내서는 **한 가지 뜻에 한 가지 말**을 씁니다. 항공 정비 문서 규격 ASD-STE100(Simplified Technical English)의 생각을 한국어 화면에 맞게 옮긴 것입니다. 규격 인증을 받은 것은 아니고, 같은 원칙을 따르는 사내 규칙입니다.

새 화면 · 문구를 만들 때 이 표를 따릅니다. `tests/test_wording.py`가 쓰지 않는 말이 화면 소스에 들어오면 실패합니다.

## 1. 용어 (쓰는 말 · 쓰지 않는 말)

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 휴대폰 | 손에 들고 쓰는 전화기. 화면 이름은 "휴대폰 화면" | 핸드폰, 폰, 모바일, 스마트폰 |
| PC | 책상 위 · 노트북 컴퓨터 | 컴퓨터, 피시 |
| 품번 / 품명 | 부품을 가리키는 번호 / 이름 | 부품번호, 부품명, 품목코드 |
| 협력사 | 부품을 납품하는 회사 | 공급업체, 공급사, 업체, 거래처 |
| 가져오기 | 파일의 내용을 QIS에 넣기 (엑셀 · 백업 · BOM) | 업로드, 불러오기, 임포트 |
| 내보내기 | QIS의 내용을 다른 형식의 파일로 만들기 (엑셀 · SQLite) | 익스포트, 추출 |
| 내려받기 | 만들어진 파일을 내 PC에 받기 | 다운로드 |
| 첨부 | 기록에 사진 · 파일을 붙이기 | 올리기 |
| 삭제 | 기록 · 파일을 없애기 | 지우기, 제거 |
| 수정 | 기록의 내용을 고치기 | 편집, 고치기 |
| 바꾸기 | 설정 · 비밀번호 · 접속 범위를 다른 것으로 정하기 | 변경하기 |
| 변경 이력 | 누가 언제 무엇을 수정했는지 남은 기록 | 수정 내역, 로그 |
| 복원 | 백업 파일로 예전 상태를 되살리기 | 복구 (※ "손상 복구 화면"은 프로그램이 스스로 고치는 경우에만) |
| 비밀번호 | 로그인에 쓰는 글자 | 암호, 패스워드 |
| 로그인 / 접속 | 로그인 = 아이디 · 비밀번호를 넣고 들어가기. 접속 = 다른 기기에서 QIS 주소를 열기 | 로그온, 연결 |

엑셀 가져오기의 **열 이름 인식**은 예외입니다. 사용자가 가진 파일에는 "부품번호" · "업체명" 같은 말이 그대로 있으므로, 인식 목록에는 옛 말도 남겨 둡니다.

## 2. 문장

1. **한 문장에 한 가지.** 지시와 이유가 둘 다 필요하면 두 문장으로 나눕니다.
2. **지시는 "~하세요"로 끝냅니다.** "~하십시오", "~해 주세요", "~바랍니다"는 쓰지 않습니다. (협력사에 보내는 통보서 본문은 예외 — 대외 문서의 경어를 따릅니다.)
3. **설명은 "~합니다 / ~됩니다"로 끝냅니다.**
4. **능동으로 씁니다.** "저장되었습니다"보다 "저장했습니다". 프로그램이 한 일은 프로그램이 주어입니다.
5. **단추는 명사 또는 "~기"로 씁니다.** 저장, 삭제, 내려받기, 가져오기. 단추에 문장을 넣지 않습니다.
6. **오류 문구는 두 부분입니다.** 무슨 일이 생겼는지 + 무엇을 하면 되는지. 예: "같은 품번이 이미 있습니다. 품번을 확인하세요."
7. **같은 것은 항상 같은 말로.** 한 화면에서 "불량"이라 부른 것을 다른 화면에서 "결함"이라 부르지 않습니다.
8. **숫자 · 단위는 붙여 씁니다.** 8자, 15분, 100MB.

## 3. 바꾸지 않는 것

- **저장된 값**: 상태(접수 · 종결 …), 귀책, 불량 유형 등 데이터에 들어 있는 말은 이 규칙으로 바꾸지 않습니다. 바꾸면 예전 기록과 어긋납니다.
- **규격 용어**: NCR, 8D, RCA, FAR, COPQ, BOM, IATF 16949의 용어는 원래 표기를 씁니다.
