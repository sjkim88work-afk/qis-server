# QIS 품질정보시스템 — 사내 설치 안내

QIS는 인터넷 서버 없이 **회사 PC 안에서** 동작하는 품질 기록 프로그램입니다. 데이터는 회사 밖으로 나가지 않습니다.

## 1. 어떤 방식으로 쓸지 정하기

| 접속 범위 | 이럴 때 | 필요한 것 |
|---|---|---|
| **이 PC만** | 품질 담당자 한 명이 기록 | 윈도우 10/11 또는 맥 PC 한 대 |
| **사내망 전체** | 여러 명이 각자 PC · 휴대폰 브라우저로 접속 | 항상 켜 둘 PC 한 대 (사무실 데스크톱이면 충분) + 사내 네트워크 |

처음에는 ‘이 PC만’으로 시작하고, 나중에 메뉴에서 ‘사내망 전체’로 바꿀 수 있습니다. 계정과 데이터는 그대로 이어집니다.

## 2. 설치 (5분)

**윈도우**
1. 받은 `QIS-windows.zip`을 **우클릭 › 속성**에서 아래쪽 **차단 해제**에 체크하고 확인을 누릅니다. (없으면 건너뜁니다)
2. **우클릭 › 압축 풀기**로 풉니다. 풀린 `QIS` 폴더를 원하는 곳에 둡니다. 예: `C:\Users\내이름\QIS`
3. `QIS` 폴더 안의 `QIS.exe`를 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 › 실행**. 관리자 권한은 필요 없습니다.
4. 자주 쓰려면 `QIS.exe` **우클릭 › 보내기 › 바탕 화면에 바로 가기 만들기**.

**백신(V3 · 알약 등)이 막을 때** — 코드 서명 인증서가 없는 빌드는 "처음 보는 프로그램"이라 막힐 수 있습니다. 전산 담당자에게 예외 등록을 요청하세요. 요청할 때 릴리스 페이지의 `SHA256SUMS.txt`에 있는 `QIS-windows.zip` 값을 함께 전달하면 됩니다.

**맥 (Apple Silicon)**
1. `QIS-mac.zip`을 더블클릭해 압축을 풉니다. 나온 `QIS.app`을 **응용 프로그램(Applications)** 폴더로 옮깁니다.
2. 처음 한 번은 `QIS.app`을 **우클릭 › 열기**로 엽니다.

## 3. 첫 실행

1. 관리자 아이디 · 이름 · 비밀번호를 정하고, 접속 범위를 고릅니다. 혼자 쓰면 ‘이 PC만’입니다. 다음부터는 이 계정으로 로그인합니다.
2. 화면 오른쪽 위 **설정**에서 회사명 · 부서 · 담당자를 넣습니다. 보고서와 통보서에 찍힙니다.
3. **설정 › 기준정보**에서 협력사와 부품을 등록합니다. 엑셀에서 복사해 붙여 넣거나 양식(.xlsx)을 받아 채워 올릴 수 있습니다.
4. 이제 **불량 등록**부터 쓰면 됩니다.

## 4. 꼭 해 둘 것: 백업 위치

데이터는 PC 안(`%LOCALAPPDATA%\QIS`, 맥은 `~/Library/Application Support/QIS`)에 있고 매일 자동 백업됩니다. 기본 백업 위치는 같은 PC라서 **디스크가 고장 나면 원본과 백업을 함께 잃습니다.**
→ 백업 폴더를 다른 디스크나 회사 공유 폴더(NAS · 파일서버)로 바꿔 두세요.
1. 프로그램 메뉴 **설정 › 저장 위치**를 엽니다.
2. **2. 자동 백업 폴더**의 **폴더 바꾸기**를 누르고 폴더를 고릅니다.
3. **지금 백업**을 누릅니다. 그 폴더에 `db` · `files` 폴더가 생기면 된 것입니다.

같은 화면의 **1. 데이터 폴더 › 폴더 옮기기**로 데이터 폴더도 옮길 수 있습니다 (예: `D:\QIS_데이터`). QIS가 데이터를 새 폴더로 복사한 뒤 닫히고, 다시 열면 새 폴더로 열립니다. 예전 폴더는 지우지 않습니다.

데이터 폴더는 NAS나 OneDrive에 두지 마세요. DB 파일이 손상될 수 있습니다. 그런 폴더를 고르면 경고가 나옵니다. 백업 폴더만 그곳에 둡니다.

## 5. 여러 명이 쓸 때 (사내망 전체)

1. 서버가 될 PC에서 메뉴 **설정 › 접속 설정 바꾸기**를 열고 접속 범위를 **사내망 전체**로 바꿉니다. 포트(기본 8080)를 정합니다. 비밀번호 칸을 비워 두면 지금 비밀번호를 그대로 씁니다.
2. **설정 › 접속 주소 보기**에 나오는 주소(예: `http://192.168.0.15:8080`)를 팀원에게 알려 줍니다. 팀원은 브라우저로 접속합니다. 휴대폰도 됩니다.
3. 관리 화면(오른쪽 위 관리)에서 팀원 계정을 만듭니다. 권한은 관리자 · 작성 · 조회 세 가지입니다.
4. 윈도우 방화벽이 "허용" 여부를 물으면 **개인 네트워크** 허용. 회사 PC에서 포트가 막혀 있으면 IT에 8080 포트 열기를 요청합니다.
5. **이 PC가 켜져 있고 QIS 창이 열려 있는 동안만** 접속됩니다. 절전 모드를 꺼 두세요.
6. 보안: 사내망 밖(인터넷)으로 열지 마세요. HTTPS가 필요하면 [데스크톱 프로그램 안내](데스크톱_프로그램.md)의 인증서 설정을 참고하세요.

## 6. 업데이트

프로그램은 새 버전을 자동으로 확인하지 않습니다. 새 버전은 저장소의 Releases 페이지에서 받고, 같은 방법으로 설치합니다. 지금 버전은 화면 머리글의 `ver x.y.z` 에서 봅니다. 데이터는 그대로입니다. 업데이트 전 **파일 › 지금 백업**을 한 번 눌러 두면 안심입니다.

## 7. 문제가 생기면

| 증상 | 조치 |
|---|---|
| 창이 하얗게 비어 있음 (윈도우) | Microsoft Edge WebView2 런타임 설치 (대부분 이미 있음) |
| "QIS가 이미 열려 있습니다" | 작업 표시줄에서 열린 QIS 창을 찾거나, 없으면 작업 관리자에서 QIS 종료 후 다시 실행 |
| 시작할 때 "지난 실행이 정상 종료되지 않았습니다" | 안내대로 **최근 백업으로 복원** 또는 **그대로 계속**. 데이터는 지워지지 않습니다 |
| 팀원 PC에서 접속이 안 됨 | 서버 PC의 QIS가 열려 있는지 · 같은 네트워크인지 · 방화벽 8080 허용 여부 |
| 관리자 비밀번호를 잊음 | 서버 PC의 메뉴 설정 › 접속 설정 바꾸기에서 같은 아이디로 새 비밀번호 설정 |
