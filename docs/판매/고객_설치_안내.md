# QIS 품질정보시스템 — 설치와 첫 실행 (고객용)

QIS는 인터넷 서버 없이 **회사 PC 안에서** 동작하는 품질 기록 프로그램입니다. 데이터는 회사 밖으로 나가지 않습니다.

## 1. 어떤 방식으로 쓸지 정하기

| 방식 | 이럴 때 | 필요한 것 |
|---|---|---|
| **이 PC 혼자 쓰기** | 품질 담당자 한 명이 기록 | 윈도우 10/11 또는 맥 PC 한 대 |
| **사내 서버로 쓰기** | 여러 명이 각자 PC · 휴대폰 브라우저로 접속 | 항상 켜 둘 PC 한 대 (사무실 데스크톱이면 충분) + 사내 네트워크 |

처음에는 혼자 쓰기로 시작하고, 나중에 메뉴에서 사내 서버로 바꿀 수 있습니다. 데이터는 그대로 이어집니다.

## 2. 설치 (5분)

**윈도우**
1. 받은 `QIS-windows.zip`을 **우클릭 › 속성**에서 아래쪽 **차단 해제**에 체크하고 확인을 누릅니다. (없으면 건너뜁니다)
2. **우클릭 › 압축 풀기**로 풉니다. 풀린 `QIS` 폴더를 원하는 곳에 둡니다. 예: `C:\Users\내이름\QIS`
3. `QIS` 폴더 안의 `QIS.exe`를 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 › 실행**. 관리자 권한은 필요 없습니다.
4. 자주 쓰려면 `QIS.exe` **우클릭 › 보내기 › 바탕 화면에 바로 가기 만들기**.

**백신(V3 · 알약 등)이 막을 때** — 코드 서명 인증서가 없는 빌드는 "처음 보는 프로그램"이라 막힐 수 있습니다. 전산 담당자에게 예외 등록을 요청하세요. 요청할 때 릴리스의 `SHA256SUMS.txt`에 있는 `QIS-windows.zip` 값을 함께 전달하면 됩니다.

**맥 (Apple Silicon)**
1. `QIS-mac.zip`을 더블클릭해 압축을 풉니다. 나온 `QIS.app`을 **응용 프로그램(Applications)** 폴더로 옮깁니다.
2. 처음 한 번은 `QIS.app`을 **우클릭 › 열기**로 엽니다.

## 3. 첫 실행

1. 사용 방식을 고릅니다. 혼자 쓰기면 이름만 넣고 시작합니다. (원하면 **비밀번호로 잠그기**를 켜 두세요 — 자리를 비울 때 안전합니다)
2. 화면 오른쪽 위 **설정**에서 회사명 · 부서 · 담당자를 넣습니다. 보고서와 통보서에 찍힙니다.
3. **설정 › 기준정보**에서 협력사와 부품을 등록합니다. 엑셀에서 복사해 붙여 넣거나 양식(.xlsx)을 받아 채워 올릴 수 있습니다.
4. 이제 **불량 등록**부터 쓰면 됩니다.

## 4. 꼭 해 둘 것: 백업 위치

데이터는 PC 안(`%LOCALAPPDATA%\QIS`, 맥은 `~/Library/Application Support/QIS`)에 있고 매일 자동 백업됩니다. 기본 백업 위치는 같은 PC라서 **디스크가 고장 나면 원본과 백업을 함께 잃습니다.**
→ 설정 › 백업 폴더를 회사 공유 폴더(NAS · 파일서버)나 OneDrive 폴더로 지정해 두세요. 1분이면 됩니다.

## 5. 사내 서버로 쓸 때

1. 서버가 될 PC에서 메뉴 **설정 › 사용 방식 바꾸기 › 사내 서버로 쓰기**. 관리자 아이디 · 비밀번호 · 포트(기본 8080)를 정합니다.
2. **설정 › 접속 주소 보기**에 나오는 주소(예: `http://192.168.0.15:8080`)를 팀원에게 알려 줍니다. 팀원은 브라우저로 접속합니다. 휴대폰도 됩니다.
3. 관리 화면(오른쪽 위 관리)에서 팀원 계정을 만듭니다. 권한은 관리자 · 작성 · 조회 세 가지입니다.
4. 윈도우 방화벽이 "허용" 여부를 물으면 **개인 네트워크** 허용. 회사 PC에서 포트가 막혀 있으면 IT에 8080 포트 열기를 요청합니다.
5. **이 PC가 켜져 있고 QIS 창이 열려 있는 동안만** 접속됩니다. 절전 모드를 꺼 두세요.
6. 보안: 사내망 밖(인터넷)으로 열지 마세요. HTTPS가 필요하면 `docs/데스크톱_프로그램.md`의 인증서 설정을 참고하거나 공급자에게 문의하세요.

## 6. 업데이트

새 버전은 공급자가 알려 드립니다 (프로그램이 자동으로 확인하지 않습니다). 받은 파일을 같은 방법으로 설치하면 됩니다. 지금 버전은 화면 머리글의 `ver x.y.z` 에서 봅니다. 데이터는 그대로입니다. 업데이트 전 **파일 › 지금 백업**을 한 번 눌러 두면 안심입니다.

## 7. 문제가 생기면

| 증상 | 조치 |
|---|---|
| 창이 하얗게 비어 있음 (윈도우) | Microsoft Edge WebView2 런타임 설치 (대부분 이미 있음) |
| "QIS가 이미 열려 있습니다" | 작업 표시줄에서 열린 QIS 창을 찾거나, 없으면 작업 관리자에서 QIS 종료 후 다시 실행 |
| 시작할 때 "지난 실행이 정상 종료되지 않았습니다" | 안내대로 **최근 백업으로 복원** 또는 **그대로 계속**. 데이터는 지워지지 않습니다 |
| 팀원 PC에서 접속이 안 됨 | 서버 PC의 QIS가 열려 있는지 · 같은 네트워크인지 · 방화벽 8080 허용 여부 |
| 비밀번호를 잊음 (혼자 쓰기 잠금) | 메뉴 설정 › 사용 방식 바꾸기에서 새 비밀번호 설정 |
| 비밀번호를 잊음 (사내 서버 관리자) | 공급자에게 문의 (서버 PC에서 명령으로 재설정) |
